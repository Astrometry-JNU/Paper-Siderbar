# Paper Sidebar · 论文阅读助手

在 Chrome 侧边栏中阅读论文：直接提取当前网页正文，让你选择的 AI 模型帮助理解研究内容、方法、创新与局限，并支持连续追问。

适合一边浏览期刊论文，一边提问和阅读解释。用户自行配置 API Key，无需部署服务器，也无需编译。

## 主要功能

- **核心内容**：梳理研究背景、问题、方法、主要结果及其意义。
- **方法讲解**：解释整体思路、关键步骤、机制与设计原因。
- **创新与局限**：分析新意、支撑证据和适用边界，区分论文结论与推断。
- **自由问答**：针对当前材料继续提问，支持复制回答、停止请求和清空对话。
- **多模型配置**：提供 DeepSeek、Qwen、Kimi、OpenAI、Gemini、Claude 及自定义 OpenAI 兼容接口的配置入口。
- **手动提供材料**：可粘贴论文段落，用于精读或处理无法直接读取的页面。

回答默认使用中文，强调重点完整、解释清楚。一般以一千字以内为宜，但不限制要点数量，内容复杂时可增加篇幅；也可以直接要求简答、详细展开或逐步解释。

## 快速安装

需要 **Chrome 116 或更新版本**。当前版本主要面向 Chrome，未验证 Edge。

1. 点击仓库上方 **Code → Download ZIP**，下载并解压源码；如仓库提供 Releases，也可以下载其中的扩展 ZIP。
2. 在 Chrome 地址栏输入 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择直接包含 `manifest.json` 的文件夹。
5. 在 Chrome 工具栏的扩展菜单中固定 **Paper Sidebar · 论文阅读助手**。
6. 打开论文的 HTML 网页，点击扩展图标打开侧边栏。

安装后请保留该文件夹，不要移动或删除。此安装方式需要手动更新。

## 配置模型

在侧边栏中打开 **设置**，选择服务商，填写以下内容，再点击 **保存并授权连接**：

| 配置项 | 作用 |
| --- | --- |
| Base URL | 模型服务的 API 根地址，可使用预设或按账号地区修改 |
| 模型 ID | 指定实际调用的模型，填写平台支持且账号有权使用的名称 |
| API Key | 验证账号并使用该账号的 API 额度 |

**具体模型由“模型 ID”决定，API Key 不会自动选择模型。** 各家配置独立保存，在主界面的“本次使用”中切换服务。

注意：

- 模型预设可以编辑，不保证始终有效；请以服务商当前提供的模型 ID 为准。
- Base URL 不要包含末尾的 `/chat/completions` 或 `/messages`，扩展会自动追加路径。
- Qwen 和 Kimi 的地址预设面向中国内地账号，其他地区应使用与密钥匹配的地址。
- 自定义接口需要支持 OpenAI Chat Completions 协议，并使用 HTTPS。
- 用户需自行准备 API Key 和可用额度；扩展不提供模型账号或 API 额度。

## 开始阅读

1. 打开期刊网站的 **HTML / Full text** 论文页面。
2. 点击侧栏中的 **读取网页**。如果提示缺少权限，点击出现的网站授权按钮并允许。
3. 展开 **查看正文 / 粘贴文字**，检查是否读到了所需章节。
4. 点击快捷按钮，或输入问题并发送。快捷键为 **Ctrl+Enter**，macOS 为 **Command+Enter**。
5. 继续提问，例如：
   - “这里的关键假设是什么？为什么需要这个假设？”
   - “请解释实验结果如何支持作者的结论。”
   - “这个方法与文中提到的已有方法有何区别？”

网页模式在每次发送前刷新材料；网页 URL 或正文变化后会清空旧对话。手动粘贴文字后，需点击 **使用这段文字**，之后问答固定围绕这段材料；点击 **读取网页** 可切回网页模式。

## 读取范围与当前限制

**读取不局限于屏幕上正在显示的区域。** 已加载到页面中、未被隐藏的正文，即使需要向下滚动才能看到，也可以被提取。

- 每次最多提供 **100,000 字符的正文**，超出会显示截断提示。字符数不是英文单词数，也不是模型的 token 数。
- 请求还包含页面元数据、提示词和最近 4 轮成功问答；实际容量受所选模型的上下文限制影响。
- 尚未加载的内容无法读取；折叠或隐藏的正文可能需要先展开。扩展不会自动滚动加载或展开全文。
- 不绕过付费墙；如果页面只有摘要，模型只能基于摘要回答。
- 本版不解析 PDF、不进行 OCR、图片分析或跨域 iframe 内容提取。PDF 可复制文字后粘贴使用。
- 正文提取使用通用规则，不保证适配所有期刊网站，可能漏掉章节或混入无关内容。请检查正文，关键结论应对照原文确认。
- 回答一次性显示，尚不支持逐字流式输出。对话保存在当前侧栏页面内存中，关闭或刷新可能丢失。

## 数据与隐私

- 没有自建中转服务器或分析埋点。点击发送或快捷按钮后，材料、页面 URL、问题和最近对话直接发送给所选 API 服务；仅点击“读取网页”时在本地提取。
- API Key 保存在本机浏览器的 `chrome.storage.local` 中，不使用浏览器云同步，仅可信扩展页面可访问。它是本地明文存储，不是加密保险库，可在设置中删除。
- 网页内容及问答的服务端处理方式取决于你选择的 API 服务。自定义地址同样会接收你填写的密钥，请使用可信地址。
- 模型调用可能产生 API 费用；停止请求不保证服务商停止计费。

扩展使用侧栏、当前标签页识别、脚本注入和本地存储权限。网站正文读取及 API 连接按域名授权，不在安装时请求所有网站的永久正文访问权限；可在 Chrome 扩展详情中管理已授予的权限。

## 更新与排错

更新时，将新版文件覆盖到原安装文件夹，在 `chrome://extensions` 点击扩展的刷新按钮，再重新打开侧栏。保持原路径且不卸载扩展，可保留模型配置。

读取失败时，先在目标页面点击扩展图标，再重试或按提示授权；无法读取的材料也可以手动粘贴。API 报错时，请检查 Base URL、模型 ID、密钥、网络和账号额度。

更多安装细节、错误码说明及版本记录见 **[使用说明](使用说明.md)**。

## 开发与反馈

基于 Chrome Manifest V3，使用原生 HTML、CSS 和 JavaScript，不依赖构建工具。修改源码后，在扩展管理页刷新即可加载变更。

| 文件 | 用途 |
| --- | --- |
| `manifest.json` | 扩展信息与权限声明 |
| `background.js` | 侧边栏打开行为 |
| `panel.html` / `panel.css` / `panel.js` | 侧栏界面、设置与问答交互 |
| `extract.js` | 网页正文和论文元数据提取 |
| `reader.mjs` | 页面类型判断与授权辅助 |
| `api.mjs` | 模型服务配置、提示词与接口调用 |

欢迎通过 Issues 反馈问题。请附上 Chrome 版本、扩展版本、可公开的网页地址、复现步骤及错误提示，**不要提供 API Key**。接口适配不代表所有模型、地区和账号均已实测。
